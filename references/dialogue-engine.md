# 中文剧本对白引擎

## 对白的任务

每句对白至少承担一种行动：

- 争取、拒绝、试探、诱导、威胁、安抚、拖延、遮掩、交换、重新定义关系；
- 提供对方此刻必须处理的信息；
- 暴露人物的知识边界、价值排序或语言习惯。

若一句台词只向观众解释双方都知道的设定，改用冲突中的不完整信息、物件、行为或后果。

## 文本与潜文本

先写本场 `对白潜台词`：

- 视点人物真正想从对方处得到什么？
- 他不愿直接承认什么？
- 他说出口的理由如何掩护真实策略？
- 对方是否识破；若识破，利用还是拆穿？

不要把潜台词写进括号或动作说明。给演员可执行的动作、停顿、回避、打断、转移和反应。

## 人物专属语言

为主要人物记录：

- 常用词域和句长；
- 教育、职业、地域和时代对语言的影响；
- 面对上位者、亲密者、陌生人时的语法变化；
- 避讳、口头防御、幽默方式；
- 压力升高时语言变短、变密、变正式或失控的方式。

不要仅靠口头禅区分人物。遮住人物名后，仍应能根据策略、知识和语言选择辨认说话者。

## 冲突层

按场景需要组合：

- 外在：时间、空间、物质环境；
- 社会：组织、制度、身份、权力；
- 个人：家庭、友谊、爱情和亲密关系；
- 私密：人物不愿面对的欲望、恐惧和自我矛盾。

对白不必每句正面冲突。沉默、误答、过度礼貌和改变话题也可以是反制。

## 修改顺序

1. 删除不影响行动、信息或人物的台词。
2. 删除双方已知事实的完整复述。
3. 把抽象判断换成当下对象、行为和选择。
4. 让回应处理对方的策略，而不只是按话题轮流发言。
5. 检查结果落差是否迫使人物改变说法或行动。
6. 朗读，修正不能自然发音、节奏单一或过度书面的句子。

## 缺陷清单

- 不可信：人物无理由说出、隐瞒或相信这些话。
- 陈词滥调：表达来自类型惯例而非此人此刻。
- 人物中性化：所有人物共享同一词汇和句法。
- 写在鼻子上：文本直接说尽潜文本。
- 解释独白：角色暂时停止行动向观众说明。
- 二人乒乓：双方只交换信息，没有第三个对象、秘密、制度或风险介入。
- 重复：同一信息或情绪没有因策略变化而升级。
- 错过时机：该沉默、打断或行动时仍继续完整说话。
