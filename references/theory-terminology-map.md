# 编剧理论术语映射

本表用于避免不同作者、译本和层级之间的误合并。关系分为：

- **基本对应**：可在当前工作流中使用同一统一字段。
- **功能近似**：解决相似问题，但边界或尺度不同。
- **层级不同**：不能一对一替换。
- **不可互换**：应保留作者原义。

| 来源术语 | 统一术语 | 层级 | 关系 | 常见误用 |
| --- | --- | --- | --- | --- |
| 菲尔德：主题 | 故事讲谁、做什么及其价值指向 | 全片 | 功能近似 | 把主题只写成抽象名词 |
| 麦基：主控思想 | 主题命题 | 全片 | 基本对应 | 省略“价值结果为何发生”的因果部分 |
| 菲尔德：戏剧性需求 | 人物外在欲望 | 人物/行动线 | 基本对应 | 用性格形容词代替可观察目标 |
| 麦基：自觉欲望/不自觉欲望 | 外在欲望/内在需要 | 人物/行动线 | 功能近似 | 假定两者必然相同 |
| 菲尔德：建置 | 初始秩序与行动问题的建立 | 幕 | 功能近似 | 把建置写成背景说明 |
| 救猫咪：布局铺垫 | 初始秩序、缺陷和待回收设置 | 阶段 | 功能近似 | 与菲尔德第一幕完全等同 |
| 救猫咪：触发事件 | 激励性扰动候选 | 全片节点 | 功能近似 | 看到任何意外都称为触发事件 |
| 麦基：激励事件 | 激励性扰动 | 全片节点 | 基本对应 | 与每场的激发动作混为一谈 |
| 菲尔德：情节点Ⅰ/Ⅱ | 幕级方向转换 | 幕边界 | 功能近似 | 把每个场景转折都叫情节点 |
| 麦基：转折点 | 造成价值变化并打开新问题的事件 | 场景至幕 | 功能近似 | 默认等于菲尔德两个情节点 |
| 菲尔德：段落 | 围绕单一动态观念组织的场景组 | 序列附近 | 功能近似 | 仅按地点或页数分组 |
| 麦基：序列 | 以更大价值变化达到高潮的场景组 | 序列 | 基本对应 | 与单场或整幕混用 |
| 麦基：节拍 | 人物行为中的动作/反应交换 | 场景内部 | 不可互换 | 当成救猫咪十五节拍 |
| 救猫咪：十五节拍 | 宏观结构诊断节点 | 全片 | 不可互换 | 当成十五个场景或麦基动作节拍 |
| 麦基：故事价值 | 故事价值 | 全片至场景 | 基本对应 | 误解为道德正确或商业价值 |
| 救猫咪：`+/-` | 入场价值到出场价值的变化 | 场景 | 功能近似 | 强迫每场只能正负二元翻转 |
| 救猫咪：`><` | 主冲突 | 场景 | 功能近似 | 只写争吵，不写目标不兼容 |
| 麦基：鸿沟 | 结果落差 | 动作至场景 | 基本对应 | 只记录失败，不记录意外成功及其代价 |
| 麦基：进展纠葛 | 递进复杂化 | 全片/幕/序列 | 基本对应 | 仅增加事件数量，不提升代价或对抗能力 |
| 麦基：危机 | 危机选择 | 高潮前 | 基本对应 | 把危险处境本身当作危机 |
| 麦基：高潮 | 高潮行动及最大价值变化 | 全片 | 基本对应 | 把最大场面、爆炸或第三幕全部叫高潮 |
| 菲尔德：结局 | 高潮后的解决阶段 | 幕 | 功能近似 | 与高潮这一单一决定性行动完全等同 |
| 麦基：结局 | 高潮后的余波 | 全片尾部 | 功能近似 | 在高潮前提前解释所有结果 |
| 麦基：文本/潜文本 | 可见言行/真实欲望与策略 | 场景/对白 | 基本对应 | 把潜文本写成括号内心理说明 |

## 使用优先级

发生冲突时依次服从：

1. 用户锁定事实和创作目标；
2. 人物知识、欲望、选择和后果的因果逻辑；
3. 因果—价值变化统一内核；
4. 项目明确启用的作者适配器；
5. 作者建议的常见页码和比例。

本 skill 的方法提炼自用户合法持有的中文版本，仅保留概念级映射和原创工作流，不收录原书段落或替代性章节摘要。
