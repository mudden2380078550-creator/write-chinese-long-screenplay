## 台账维度

稳定状态与摘要分开维护：

- 人物：位置、身体、伤势、服装、物品、能力、目标、阵营；
- 知识：事实、来源、可信度、获知场次、是否已分享；
- 关系：信任、亲密、依赖、怨恨、公开/私下身份、承诺；
- 时间：世界时间、经过时长、交通、季节、截止时间；
- 物件：位置、持有人、外观、损坏、真伪、谁见过；
- 线索：观察事实、表面解释、真实解释、观众曝光、状态；
- 线程：承诺、拥有者、当前阶段、上次变化、下一压力、回收条件；
- 制作连续：妆发、血迹、天气、群众状态、特殊场景限制。

状态变化写成：

```json
{
  "dimension": "knowledge",
  "subject": "char-zhou-lan",
  "before": "不知道录音存在",
  "cause": "E003-S012 听见林乔播放前十秒",
  "after": "知道有录音，但不知道来源",
  "evidence": "E003-S012"
}
```

## 观众模型

分开记录：

| 层 | 内容 | 算作观众已知？ |
| --- | --- | --- |
| 作者真相 | 隐藏历史、未来事件、真实机制 | 否 |
| 人物认知 | 人物知道、相信或回避的内容 | 只有正文外显部分 |
| 观众证据 | 正文已呈现的画面和声音 | 是 |
| 预期推断 | 目标观众可能得出的结论 | 编辑假设，需复核 |

每个关键转折复原：

- 观众现在能描述什么；
- 观众可能相信什么，证据是什么；
- 仍在追问什么；
- 预计下一步发生什么；
- 当前情绪由哪个视听事实触发。

不能从场次卡、大纲、改稿备注推断观众知道。

## 伏笔与揭示

揭示卡：

```yaml
truth:
surface_model:
seed_evidence: []
reader_exposure: []
character_exposure: []
misdirection_with_cause: []
reframe_scene:
choice_consequence:
```

优先使用：

`呈现 → 被正常化或误读 → 出现矛盾 → 重构 → 强迫选择`

隐藏意义、权限或动机，不要隐藏人物必然会注意到的事实。误导必须有真实原因，如羞耻、保护他人、制度利益、另一件过错或被操纵的证据。

## 改稿影响图

把意见转成可验证问题：

| 意见 | 根因假设 | 首个需改场 | 下游影响 | 锁定项 | 验收标准 |
| --- | --- | --- | --- | --- | --- |
| “主角不讨喜” | 选择只伤害别人，未显示代价 |  |  |  |  |
| “中段拖” | 连续场次不改变决策空间 |  |  |  |  |
| “反转突兀” | 观众缺少可回忆证据 |  |  |  |  |
| “对白像作者” | 角色目标未进入句子 |  |  |  |  |

操作顺序：

1. 找到症状首次出现处；
2. 区分根因场和显症场；
3. 列出受影响的知识、关系、物件、线索和线程；
4. 锁定不变项；
5. 先修改最早根因；
6. 顺时间检查后续反应；
7. 更新台账与修订日志；
8. 编译并回归。

## 回归检查

- 场号与文件名仍同步；
- 角色没有提前知道修改后的信息；
- 被删除铺垫不再支撑后续结论；
- 新道具或伤势有来源、有消失条件；
- 对白称谓符合关系当前状态；
- 交通、昼夜和截止时间仍可能；
- 反转后的至少一个行动发生变化；
- 改稿没有让已锁定场失去必要前因；
- 集末钩子仍由本集选择产生；
- 导出稿未混入场次卡和改稿备注。

## 常见故障

- 摘要保留事件，却丢失谁知道、谁欠谁、物件在哪。
- 修改真相后没有重算线索、证词和不在场证明。
- 为修一个对白问题整体重写人物声线。
- 把大纲新方案提前登记为正典。
- 删除一场却忘记下场的情绪承接。
- 用更多解释修补缺失的视听前提。
- 把所有警告都当错误，消灭了有意含混。
