## 电影工程阶段

按以下顺序推进，除非用户已有成熟材料：

1. 核心命题与观众承诺；
2. 人物小传、关系网络、背景和世界观；
3. 一句话梗概与一页梗概；
4. 故事处理稿；
5. 幕/序列结构；
6. 逐场大纲；
7. 电影剧本初稿；
8. 自审与改稿；
9. 锁场号拍摄稿。

前一阶段是后一阶段的约束，不是需要复制进正文的说明文字。

## 核心创作源

### 人物小传

至少包含：

- 当前欲望和长期需要；
- 错误信念或自我保护方式；
- 前史中的关键选择及残留后果；
- 社会身份、资源、义务与弱点；
- 关系中的需要、依赖、筹码和边界；
- 知识、秘密、误解和盲点；
- 压力下的行为模式；
- 语言指纹；
- 电影开始到结束的可观察变化。

### 故事背景

记录发生在电影开始前但仍然产生压力的事实：

- 历史事件；
- 家庭、机构或社会旧账；
- 已经发生的损失和承诺；
- 公共叙事与真实历史的差异；
- 当前仍可见的空间、物件、法律、名誉或关系结果。

背景如果不改变现在的选择，就不应占据正文说明篇幅。

### 世界观

记录：

- 日常基线；
- 地点和机构；
- 权力、资源和进入权限；
- 技术、超自然或制度能力；
- 限制、成本、失败方式和例外；
- 哪些人物知道哪些规则；
- 规则如何影响普通生活。

## 结构选择

按故事选择结构，不强制套用单一模板：

- 三幕：适合清晰的承诺、升级和危机选择；
- 五幕：适合多次权力反转或悲剧推进；
- 八序列：适合以约 10–15 分钟为压力单元管理长片；
- 调查链：问题 → 方法 → 证据 → 模型变化；
- 关系链：旧交换 → 压力 → 越界 → 识认 → 新关系；
- 任务/旅程：目标 → 阶段障碍 → 资源损失 → 价值重估；
- 多线汇合：多条人物线必须在共同选择或后果上汇合。

结构节点必须由选择和后果定义，不只由分钟数命名。

## 处理稿

处理稿用现在时讲完整电影，包含：

- 场景发生在哪里；
- 谁在场；
- 人物试图做什么；
- 阻碍如何变化；
- 观众看见和理解什么；
- 人物选择造成什么后果；
- 关系、信息和世界状态如何进入下一段。

处理稿可以概述对白功能，但不要提前写大量对白。无法在处理稿中解释清楚的因果，进入正文后通常不会自动变清楚。

## 序列与逐场大纲

每个序列记录：

| 项目 | 内容 |
| --- | --- |
| 进入状态 | 人物、关系、计划和观众模型 |
| 序列任务 | 本序列必须完成的主要变化 |
| 压力来源 | 人物、制度、时间、空间或规则 |
| 关键选择 | 谁关闭了哪条退路 |
| 序列转折 | 哪个事实或后果改变了下一步 |
| 退出状态 | 新目标、新代价和新问题 |

逐场大纲记录：

- 场号和结构位置；
- 地点、日夜、内外；
- 来源文件；
- 人物即时目标；
- 背景/世界规则如何产生压力；
- 观众入口信息；
- 策略、反制和换招；
- 场面转折；
- 观众更新；
- 出场状态；
- 接场因果。

## 正文写作

- 电影场次使用 `S001.md`，场景标头使用 `场景标头：1 地点 日 内`。
- 一场只保留一个主要戏剧任务和一个主要观众更新。
- 人物小传通过选择模式、回避、关系礼仪、语言指纹和代价显现。
- 背景通过当前仍然有效的伤口、制度、物件、空间和债务显现。
- 世界观通过能力、限制、成本和普通行为显现。
- 说明性信息只有在改变当前策略、关系或风险时进入对白。

## 电影节奏审查

分钟和页数仅作诊断，不替代戏剧判断。检查：

- 开场是否建立当前生活的代价，而非只展示氛围；
- 触发事件是否使旧办法失效；
- 第一幕结束是否包含主动承诺或被迫关闭退路；
- 中段是否改变目标、模型、权力或代价，而非只增加事件；
- 后半段是否兑现前半段建立的规则和关系；
- 危机是否移除“两全”方案；
- 高潮是否由主角使用已建立机制做选择；
- 余波是否用行为展示新状态和剩余代价。

连续三场若具有相同功能、策略和情绪形状，应合并、重排或改变任务。

## 修订与锁场号

- 创作稿可以重排场次，但每次改动更新逐场大纲和台账。
- 拍摄稿锁号后不自动复用删除场号。
- 插入场使用项目约定的插入号，不能由脚本擅自决定。
- 修改人物前史、世界规则或真相时间线时，重算所有下游场次。
- 编译稿是输出，所有修改回到 `screenplay/scenes/`。
