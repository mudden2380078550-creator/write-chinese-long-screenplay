# 因果—价值变化内核

## 统一层级

| 层级 | 必须回答的问题 | 典型产物 |
| --- | --- | --- |
| 全片 | 何种选择证明何种价值判断 | 主题命题、结局价值 |
| 行动线 | 主角长期追求什么，为什么不能退出 | 外在欲望、内在需要、核心行动线 |
| 幕/阶段 | 哪次不可逆选择改变了行动方向 | 结构图 |
| 序列 | 一组场景共同完成什么阶段任务 | 序列地图 |
| 场景 | 谁想改变什么，现实如何反击 | 场次卡、正文 |
| 动作节拍 | 策略或反应何时改变 | 动作、对白、沉默 |

不要把层级不同但都译作“节拍”或“转折”的概念当作同一单位。

## 全片因果链

按下列顺序建立统一结构：

1. **主题命题与反命题**：分别写成“某种价值结果，因为人物以某种方式行动”。不要写抽象口号。
2. **主角欲望**：外在欲望必须可观察；内在需要可以在早期不自知，但必须通过行为模式体现。
3. **激励性扰动**：打破稳定状态，使主角原有策略不再足够。
4. **递进复杂化**：对抗力量学习和适应，代价、范围或不可逆性逐步增加。
5. **不可回头点**：主角的选择关闭便宜退路，不只是外界偶然封路。
6. **危机选择**：在互不兼容且均有代价的方案中选择。
7. **高潮行动**：把危机选择落实为不可撤回的行动，并造成全片最大价值变化。
8. **结局价值与余波**：展示选择后的新秩序、损失和仍未消失的代价。

结构节点必须用“人物选择 + 后果”定义。页码、分钟数和作者体系标签只用于诊断。

## 场景生成链

每场先填写：

| 字段 | 要求 |
| --- | --- |
| 视点人物 | 必须是本场 `characters` 中的人物 |
| 场景目标 | 该人物在本场结束前想造成的可观察变化 |
| 故事价值 | 本场真正变化的经验维度，如信任、自由、安全、权力 |
| 入场价值 | 开场时该价值在具体关系或处境中的状态 |
| 主冲突 | 阻止目标的主动对抗、制度、环境或内在限制 |
| 策略 | 视点人物为达成目标采取的第一种办法 |
| 预期结果 | 人物相信策略会带来的结果 |
| 实际结果 | 正文实际发生的结果 |
| 结果落差 | 预期与实际之间的差异，以及差异为何迫使人物换招 |
| 场面转折 | 行动、反制或新证据改变力量关系或理解 |
| 出场价值 | 结尾时同一故事价值的新状态 |
| 下场压力 | 本场后果使后续必须处理的问题 |

`入场价值` 与 `出场价值` 不能只是换一种说法。若价值没有改变，合并、删除或重新设计该场。

## 来源转场景

不要把人物小传、背景和世界规则直接复制进对白。依次转换：

1. 找出与当前目标相关的来源事实。
2. 判断事实此刻提供资源、限制、风险还是误导。
3. 让人物按其欲望、错误信念和已有知识选择策略。
4. 让对抗力量具体反制。
5. 用动作、物件、空间、声音或他人反应提供证据。
6. 记录观众能够推断的内容和仍应未知的内容。
7. 把本场结果写入连续性台账。

## 语义检查

- 是否存在人物显然会选择的更便宜方案？若有，建立不能使用它的原因。
- 对抗是否会根据主角前一次行动而调整？
- 转折是否来自已经建立的机制、人物或证据？
- 场景结束后，人物的资源、关系、知识、承诺或价值位置是否改变？
- 下一场是否因本场结果而变得必要，而不是仅仅“然后又发生”？
