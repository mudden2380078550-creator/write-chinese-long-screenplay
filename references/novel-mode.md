# 中文长篇小说模式

## 适用请求

当用户说“小说、长篇、章节、卷纲、连载、网文、正文、EPUB、章节续写”时，选择小说模式。若用户同时提到剧本格式、场次或拍摄执行，先询问其当前交付物是小说还是剧本，不要自动混用。

## 创作输入

小说模式默认只要求作者维护：

1. `background/story-background.md`：背景、世界规则、资源、限制、代价和作者真相；
2. `bible/characters/*.md`：人物欲望、需要、误信、秘密、知识边界、关系、语言和最终选择。

全书总纲、卷纲、章节大纲、故事状态和读者信息模型由 Skill 内部生成和维护。

## 内部生成链

```text
作者输入 → 作品承诺 → 核心压力 → 主线与副线
→ 多卷/多幕结构 → 单元/序列 → 章节任务
→ 继承状态 → 压力 → 选择 → 后果 → 交接
```

每章必须定义：入口状态、唯一主任务、人物行动、阻力、不可逆变化、读者获得的信息、出口问题和下一章钩子。

## 小说项目资料

- `plot/master-plot.md`：全书主线、卷弧、主题命题和结局条件；
- `outlines/master-outline.md`：卷、单元、章节地图；
- `chapters/`：发布正文；只有 `## Draft` 是正文正典；
- `ledger/story-ledger.json`：人物状态、时间、关系、物件、线索和开放问题；
- `ledger/author-decisions.md`：作者唯一决策登记；
- `reviews/`：连续性、读者模型和回归报告。

## 小说与剧本的边界

小说写可读正文、叙述视角、内心、节奏和段落；剧本写可拍摄动作、场面标头、对白和场次变化。不能把小说章节直接当成剧本场次，也不能让剧本对白承担小说旁白功能。

## 小说完成门禁

- 章节出口与入口有实际变化；
- 新事实有来源，且已标注是作者真相、人物知识还是读者证据；
- 伏笔、物件、时间和关系变化已回写台账；
- 没有未经作者确认的新正典事实；
- 章节正文不含方案分支和协作元话语；
- 结构问题先修大纲，不能用注水场景掩盖。
