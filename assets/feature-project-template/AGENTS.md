# 中文电影剧本项目规则

## 正典

- `screenplay/scenes/` 是电影正文正典，场次使用 `S001.md`。
- `background/`、`bible/`、`outline/`、`style/` 和 `ledger/` 是创作与连续性依据。
- `reviews/` 和 `exports/` 是可再生输出。
- 锁定稿高于大纲；用户当前明确指令最高。

## 生成正文

- 写场前读取相关人物小传、故事背景、世界规则、逐场大纲和相邻场次。
- 在 frontmatter 的 `source_files` 记录本场使用的来源。
- 人物小传通过选择、习惯、称谓、回避和策略显现，不改写成自我介绍。
- 背景和世界观通过当前压力、规则、空间、物件与后果显现。
- 不把人物卡中的秘密当成人物或观众已经知道。

## 格式

- 动作段以 `△` 开始。
- 对白使用 `人物名：对白`。
- 场景标头使用 `场景标头：1 地点 日 内`。
- 正文只写可见、可听、可表演内容。

## 改稿与自审

- 局部意见不授权整体重写。
- 不静默重排锁定场号。
- 修改前史或世界规则前列出全部下游影响。
- 每完成一个序列或初稿，运行结构校验和自审。
- 修复阻断问题后重新进行观众盲读。
