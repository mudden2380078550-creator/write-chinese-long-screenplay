# 中文长剧本项目规则

## 正典

- `screenplay/scenes/` 是场次正文正典。
- `project.md`、`bible/`、`outline/`、`style/` 和 `ledger/` 是规划与连续性证据。
- `exports/` 是可再生输出，不作为修改源。
- 用户明确指令高于项目文件；锁定场次高于大纲。

## 写作

- 作者面向内容默认使用简体中文。
- 场次文件名固定为 `E001-S001.md`。
- `## 正文` 只写可见、可听、可表演内容。
- 动作段以 `△` 开始；对白写作 `人物名：对白`。
- 不把人物卡中的秘密当成人物或观众已经知道。
- 新事实被确认后更新 `ledger/story-ledger.json`。

## 改稿

- 局部意见不授权整体重写。
- 不覆盖、复用或静默重排已锁定场号。
- 改设定前列出影响的场次、人物知识、线索、道具与线程。
- 编辑已有场次时保留稳定 ID 和未要求修改的内容。

## 校验

- 新建或修改场次后运行结构校验。
- 编译前确保结构错误为零。
- 警告需要人工判断，不以机械清零为目标。
