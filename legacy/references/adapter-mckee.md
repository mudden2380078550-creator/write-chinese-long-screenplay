# 麦基结构与场景适配器

只在 `structure_adapters` 包含 `mckee`，或用户要求主控思想、故事价值、鸿沟、进展纠葛、危机、高潮、文本与潜文本时读取。

## 映射

| 麦基术语 | 统一内核 |
| --- | --- |
| 主控思想 | 主题命题：价值结果及其原因 |
| 激励事件 | 激励性扰动 |
| 故事脊椎/求索 | 主角核心行动线 |
| 故事价值 | 场景和全片衡量变化的经验维度 |
| 鸿沟 | 预期结果与实际结果之间的结果落差 |
| 进展纠葛 | 递进复杂化 |
| 危机 | 高潮前不可兼得的危机选择 |
| 高潮 | 由危机选择落实的决定性行动与最大价值变化 |
| 结局 | 高潮后的余波 |
| 文本/潜文本 | 可见言行与其下真实欲望、策略和冲突 |

## 场景设计

1. 明确人物想要的对象或变化。
2. 让人物基于现有知识采取策略，并形成具体预期。
3. 让现实、他人或人物自身产生与预期不同的反应。
4. 用结果落差迫使人物调用更高风险的策略。
5. 让转折改变同一故事价值的状态。
6. 以新的压力、问题或不可逆承诺结束。

场景的价值变化不必机械地只在正负两极跳转，但必须具有可辨认的实质变化。

## 全片设计

- 让对抗力量的能力至少与主角相称，并能学习主角的策略。
- 让复杂化提升代价、范围、亲密度或不可逆性，而不是只增加数量。
- 把危机写成选择，不写成单纯危险。
- 让高潮给出全片主控思想的最终证据，不用台词宣告主题。

## 对白检查

- 台词是否同时推动行动、提供必要信息并显露人物？
- 人物说出的文本与真正欲望之间是否存在可表演距离？
- 是否“写在鼻子上”，把真实思想直接说尽？
- 冲突是否覆盖外在、社会、个人和私密层中的相关层次？
- 删除台词后，演员是否仍能从行为和关系中找到潜文本？
