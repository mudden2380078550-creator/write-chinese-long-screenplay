## 来源层级

把输入分成：

- **硬约束**：已确认身份、时间、规则、伤势、关系和已发生事件；
- **人物模型**：欲望、需要、恐惧、习惯、语言和认知边界；
- **戏剧计划**：梗概、处理稿、序列和逐场大纲；
- **候选材料**：未确认场景种子、对白种子和备选设定；
- **未知项**：尚未决定或有多个解释的内容。

硬约束不可静默改变。计划不是已发生事实。候选材料只有被用户确认或写入正文后才成为正典。

## 选择相关事实

不要把整份人物小传和世界观塞入单场。只选择会影响本场以下任一项的事实：

- 人物想要什么；
- 人物能做和不能做什么；
- 人物如何解释对方行为；
- 人物愿意付出什么代价；
- 空间、制度或规则允许什么；
- 观众需要看到什么才能理解下一步；
- 场次结束时什么必须改变。

## 戏剧化转换

为每个选中的来源事实填写：

| 来源事实 | 当前压力 | 人物策略 | 视听表达 | 观众可推断 | 不可直说/不可矛盾 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

转换优先级：

1. 让事实限制人物选择；
2. 让事实改变人物策略；
3. 让事实造成空间、资源或关系后果；
4. 让观众从行为与反应推断；
5. 仅在行动必须依赖该信息时说明。

## 人物小传到行为

不要写“顾晴从小缺乏安全感”。改写为当前可观察行为：

- 她进入房间先确认出口；
- 她接受帮助前先问价格；
- 她把感谢改说成任务安排；
- 她在关系变亲密时转用正式称谓。

人物一致性不是永远做同一种事。变化必须有触发点、代价和可见选择。

检查每个主要行动：

- 这是谁的目标？
- 该人物此刻知道什么？
- 哪段前史改变了他对风险的判断？
- 他为什么选择这种策略，而不是更容易的策略？
- 对方如何根据自己的小传误读或反制？

## 背景到当前压力

背景通过“残留物”进入正文：

- 未清偿债务；
- 仍有效的法律和制度；
- 被占用或废弃的空间；
- 旧事件留下的伤势、名誉、照片、档案或禁忌；
- 关系中的旧称谓、仪式和回避；
- 不同人物对同一历史的冲突版本。

背景段落不能只负责补课。它必须改变当前行动或观众对当前行动的解释。

## 世界观到规则后果

按以下顺序呈现：

`日常使用 → 限制或成本 → 人物利用/误判 → 后果 → 更准确模型`

奇幻、科幻和制度规则均需记录：

- 能力；
- 前提；
- 限制；
- 成本；
- 失败模式；
- 已知例外；
- 谁知道规则；
- 观众在哪场见过证据。

高潮不能第一次出现决定性能力或例外。

## 对白生成

人物不是设定说明员。写对白前给每人一个言语行动：

- 索取；
- 拒绝；
- 掩饰；
- 试探；
- 重新定义责任；
- 争夺解释权；
- 拖延；
- 安抚；
- 威胁；
- 交换。

将来源信息放进利益冲突。共同知道的背景，不用“你还记得”“你也知道”重新介绍。

对白生成后检查：

- 删除人物姓名后，是否仍能从句法、称谓、回避和攻击方式判断说话者；
- 每句是否在对另一个人物做事；
- 解释是否改变当前选择；
- 潜台词是否能由动作或反应支持。

## 来源追溯

场次 frontmatter 使用：

```yaml
source_files:
  - bible/characters/gu-qing.md
  - background/story-background.md
  - bible/world/tide-rule.md
```

场次卡记录当前真正使用的：

- 人物依据；
- 背景依据；
- 世界规则；
- 禁止矛盾。

来源追溯不是要求正文复述来源，而是允许自审时判断人物和世界是否失真。

## 失效模式

- 把人物小传改写成长篇自白。
- 用旁白讲世界观，却没有规则后果。
- 人物为了传递信息而提出自己已知道的问题。
- 每个角色都完整表达主题。
- 背景只解释过去，不改变现在。
- 只引用来源文件名，没有指出本场使用的具体事实。
- 为制造反转，隐藏视点人物必然会想到的内容。
- 人物突然违背小传，且没有触发事件和代价。
