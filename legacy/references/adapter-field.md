# 菲尔德结构适配器

只在 `structure_adapters` 包含 `field`，或用户明确要求三幕示例、情节点、段落法时读取。

## 映射

| 菲尔德术语 | 统一内核 |
| --- | --- |
| 主题 | 人物、行动与价值指向 |
| 戏剧性需求 | 主角外在欲望 |
| 建置 | 初始秩序、人物、前提和行动问题 |
| 对抗 | 递进复杂化与适应性反制 |
| 结局 | 危机、高潮行动、结局价值和余波 |
| 情节点Ⅰ | 主角选择进入主要行动线的幕级方向转换 |
| 情节点Ⅱ | 把主要行动线推向危机与高潮的幕级方向转换 |
| 段落 | 围绕一个动态观念和阶段任务组织的场景组 |

## 操作步骤

1. 先确定结局价值和高潮行动，再回推开场必须建立的资源、关系和缺陷。
2. 用一句话写出每个段落的动态观念，例如“主角尝试用制度内部方法取得证据”。
3. 为情节点填写：人物当时目标、选择、关闭的退路、新方向和代价。
4. 检查第二幕是否由不断调整的行动方案组成，而不是重复受挫。
5. 把页数和分钟数视为粗略诊断。不同片长、类型和叙事形式可以偏离。

## 失败信号

- 情节点只是外部巧合，没有人物选择。
- 第一幕只解释背景，未形成行动问题。
- 第二幕由可互换的障碍填充。
- 第二情节点直接提供答案，使高潮不再需要人物承担代价。
- 把菲尔德两个幕级情节点当成所有场景转折的名称。
