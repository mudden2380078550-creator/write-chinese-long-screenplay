# v0.4.0 — 泛长篇创作 Harness

本次发布来自 `refactor/harness` 分支，替换该分支的项目布局；`main` 和旧标签保持不变。

## 新增与重构

- 独立、无第三方运行依赖的 Python 核心；工具、Skill安装副本、作品目录分离。
- 人物、技能、资源、作者政策和章节大纲独立持久化；每章构建上下文。
- prepare → submit → check → accept 工作流，正文与状态通过可恢复事务共同接受。
- 技能成本、冷却、版本冲突、重复接受、上下文预算和手工篡改检查。
- 历史写前状态、章节重新审查、独立修订副本、v2复制迁移与来源归档。
- 宿主AI从资料包填写结构化提案；独立Skill安装器备份旧版本。
- 修复并保留 legacy 兼容层，恢复原 GPLv3 LICENSE，更新中英文 README。
- CI统一Python UTF-8模式，避免Windows默认cp1252错误解码中文子进程输出。

## 安装与迁移

需要 Python 3.10+。下载本 Release 的 Source code，解压后执行 `python scripts/harness.py --help`。安装Skill请执行：

```text
python scripts/install_skill.py --destination <skills目录>/write-chinese-long-screenplay --backup-root <备份目录>
```

不要把整个新仓库直接复制到skills目录。旧dsh根目录插件安装方式不适用于新布局。作品必须与工具分开保存；升级前备份，v2作品使用 `project migrate --help` 的复制迁移入口并审定报告。内部开发版0.3.0项目继续使用原工具，不手改版本锁。

## 验证与边界

Windows本地验证：核心33测、legacy17测；跨平台CI已配置，发布时以对应提交的 Actions 结果为准。工程测试不代表文学质量评估。

不内置模型API，不提供云同步或分布式写锁。语义审查依赖作者/宿主，无法证明小说没有语义问题；v3剧本不宣称完全移植旧场次约束。
